# Agent Sentinel Design System

Source: applied from `ui-ux-pro-max-skill` guidance for a cybersecurity platform / real-time monitoring dashboard.

## Product Type

Cybersecurity platform, AI agent EDR, SOC dashboard, runtime monitoring.

## Recommended Pattern

- Data-dense dashboard
- Real-time monitoring
- Trust and authority enterprise layout
- Drill-down analytics panels
- Incident response workflow

## Visual Style

- Dark Mode OLED
- HUD / Sci-Fi FUI accents, but restrained and enterprise-grade
- Swiss enterprise dashboard structure
- Dense cards, tables, timelines, score bars
- No playful AI purple/pink gradients
- No emojis as icons

## Colors

- Background: `#030712`, `#05070d`
- Surface: `#070d18`, `#0b1220`, `#111827`
- Border: `#142034`, `#1f3350`, `#284365`
- Text primary: `#f8fbff`
- Text secondary: `#91a4c2`
- Text muted: `#7d8da8`
- Accent cyan: `#38bdf8`
- Accent green: `#22c55e`
- Warning: `#f59e0b`
- Critical: `#ef4444`
- Purple graph/tool accent: `#a855f7`

## Typography

- Primary: Inter / system sans-serif
- UI mood: enterprise, technical, precise
- Use uppercase tracking only for labels/eyebrows
- Use tabular numbers for KPI and score displays

## Components

- KPI card
- SOC timeline row
- Risk score bar
- Severity pill
- Security graph node
- Incident evidence card
- Baseline score card
- Tool trust row
- Command center header

## Accessibility Checklist

- Visible keyboard focus states
- Button hover and active states
- Contrast >= WCAG AA for body text
- Reduced motion support
- Responsive breakpoints: 375, 768, 1024, 1440
- Avoid relying on color only; include labels and scores

## Anti-Patterns

- Consumer AI chatbot aesthetics
- Emoji icons
- Large empty marketing sections
- Overly soft gradients
- Low-contrast gray text
- Decorative animations that obscure dense data
